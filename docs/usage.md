# 中文界面、按键与 Muse 命令

Muse Pocket 是 Muse 的随身显示屏，接收配对连接发送的角色图与状态，不提供公开网页 API，也不会独立订阅活动流。

下述呼叫与分页行为属于源码开发中的 **`0.1.6-call-zh` 实验版本**，暂无公开 release，尚待实机验证。已发布 `0.1.5-coexist-zh` 不包含这些新操作；其资产与摘要不变。配置预设和故障边界见 [左键呼叫指南](call-muse.md)。

## 按键

- 主屏右键：打开设置；设置中右键：选择下一项。
- 设置中电源键：修改当前项。
- 主屏电源短按：完整刷新；长按 3 秒：休眠；电源键唤醒。
- 左键短按：配对过程中确认；未配对时按原设置流程处理；结果页中翻页，末页再按返回角色图；无正文的错误提示可短按清除。呼叫等待中短按被忽略。
- 已配对时长按左键 2 秒：呼叫 Muse 执行已保存的「X4 Pro 左键预设」；设置菜单中触发会先关闭菜单。等待结果时重复触发不会重发。
- 初始化设置尚未完成、且非等待配对确认时：保留左键长按 5 秒重置设置。日常已配对使用不会因此清除配对；配对确认中长按不确认、不呼叫，确认仍用短按。
- 双击左键被忽略，不会重新扫描 Wi-Fi。

设置提供亮度、色温、刷新间隔（2/5/15/30 秒）、方向、语言、休眠、系统切换和返回 Muse。语言默认简体中文；显示设置存入单独的 `muse_pocket` 区域。`0.1.5-coexist-zh` 配套 CrossMux 环境显示 **切换到 CrossMux**；旧 CrossPoint 环境显示 **返回 CrossPoint**。选中该行后长按电源 3 秒切换，短按不会切换。

CrossMux 中的入口是 **设置 → 系统 → 切换到中文 Muse**。安装和升级需要配套版本，见 [共存指南](crossmux-coexistence.md)；普通 Nightly 不能直接替换专用 CrossMux。

状态按选定间隔批量刷新，图像更改使用完整刷新；累计十次局部更新后也会完整刷新。

## Muse 可调用的命令

| 命令 | 参数 | 行为 |
| --- | --- | --- |
| `display.draw_url` | `url`，可选 `row` | 显示角色图，保留状态 |
| `pocket.set_status` | `text`，最多 240 UTF-8 字节 | 修改角色图下方状态 |
| `pocket.complete_call`（0.1.6 开发功能） | 当前 `call_id`；`text` 为 1–3072 UTF-8 字节 | 完成匹配呼叫，在角色图区域分页显示结果 |
| `pocket.set_frontlight` | `brightness`、`warmth`，0–100 | 修改并保存前光 |
| `display.show_animation` | 无 | 返回中性占位图 |

图片使用适合 **480×480** 角色区域的 **baseline JPEG**，或大端 RGB565 原始数据。图片以黑白抖动显示，下载不完整时保留旧角色图。

名字和状态支持中文与 ASCII 混排，状态按像素宽度换行，最多显示四行。字节上限不等于中文字数；换行和截断保持完整 UTF-8 字符。未覆盖的生僻字、其他文字与 emoji 使用替代字形。

```json
{"text":"正在整理笔记。\n接下来：起草回复。"}
```

长按左键后显示 **正在呼叫 Muse**；普通状态命令不会覆盖呼叫界面。HTTP 2xx 仅表示触发请求被接受，只有匹配的 `pocket.complete_call` 才算返回结果。三分钟没有回调显示 **状态未知**，不自动重发；断线或退出本地页面后，已经发出的任务仍可能运行。先到 Muse 检查任务，避免重复执行副作用。完整预设模板与风险应对见 [呼叫指南](call-muse.md)。

## 自动初始化

配对连接注册后，固件向 Muse 主聊天发送一次请求，要求它发送自己的角色图，并在实际活动变化时调用状态命令。普通重连不重复发送，重启后会再次请求，因为角色图只保存在内存。

这是请求，不保证 Muse 每次活动都主动更新；命令必须由 Muse 实际执行。

## 排查

- 已连接但没有角色图：请求 Muse 调用 `display.draw_url` 发送 480×480 baseline JPEG，再调用 `pocket.set_status` 发送中文状态，并报告每个命令的结果。
- 名字仍为 Muse Pocket：身份请求尚未返回，检查 Muse 连接并等待重连。
- 状态不变：确认 Muse 是否实际调用新的状态命令。
- 重连中：检查 Wi-Fi 和 Muse 服务；普通重连保留旧图与状态。
- 恢复固件未验证：双系统按 [恢复指南](crossmux-recovery.md) 检查；旧 CrossPoint 环境按 [旧版指南](install.md) 检查，不绕过摘要或签名校验。
- 屏幕空白或卡住：Muse 开始启动时按住右键至少 1.2 秒，尝试切换到仍完整且通过校验的配套 CrossMux（旧环境为 CrossPoint）。这条故障恢复路径尚未单独验收，不盲目改硬件引脚或刷其他型号。

中文覆盖、许可证和实机验证限制见 [中文说明](chinese.md)。反馈问题时可提供操作步骤、版本与屏幕照片；不要附个人安装包、SDK token、设备 token、Wi-Fi 密码或 sdkconfig。
