# 中文显示说明

## 实现方式

使用有界 UTF-8 解码与按像素宽度排版。ASCII 沿用原来的 5×8 点阵，中文使用内置 16×16 单色点阵。状态保留四行与手动换行，支持中英混排；名字和状态只在完整字符边界截断。未覆盖字符使用一个替代字形。

菜单、配对与连接提示默认简体中文。语言选择保存在已有的 `muse_pocket` 设置区域，切换语言不会重置配对、SDK 凭据或 Wi-Fi。

## 字符覆盖

内置字库包括原字体中实际存在的：

- CJK 统一汉字 U+4E00–U+9FFF。
- CJK 标点 U+3000–U+303F。
- 全角与半角字符 U+FF00–U+FFEF。
- 常用标点 U+2010–U+2027，包括中文文本常用的弯引号、破折号和省略号。

覆盖常见简体和繁体汉字，但菜单使用简体中文。不承诺 CJK 扩展区、生僻字、emoji 或其他文字的完整显示，也不实现复杂文字整形。精确覆盖、原字体来源和 SHA256、OFL 许可证见 `esp32/main/fonts/`，可复现生成工具见 `tools/fonts/`。

字形是固件中的常量，不在启动时解压，不需运行时字体库或 SD 卡字体。

## 验证

当前为预发布。UTF-8 与换行自动化测试、ESP32-S3 编译记录随发布说明提供；构建通过或本机预览不能代替实机验收。

中文名字、状态、菜单语言、Muse 重连和返回 CrossPoint 需在实际 X4 Pro 上检查。改动前上游版已完成用户实机配对与显示，那不能证明本次中文固件已通过实机验证。

## 安装边界

保留应用更新流程、个人打包流程、原 token 保留槽、配对存储与准确 CrossPoint 1.6.5 恢复摘要。此次不添加远程 OTA。公开发布只能包含无凭据应用镜像，每个用户必须在本机打包自己的 token。
